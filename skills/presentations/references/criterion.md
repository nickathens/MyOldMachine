Criterion is a catalog logic applied to film. The palette is an off-white, a true black, and a vermilion red that appears where a scholar's underline would. Type is a grotesque close to Founders Grotesk for utility; long-form writing uses editorial serifs in the Lyon/Tiempos family.

The grid is strict. The cover art is commissioned like a book jacket, never like a poster. Titles sit in hierarchies that reward reading. The aesthetic feels like a library that cares.

A treatment leaning on Criterion should behave like an archival edition. Keep the background off-white, not pure paper. Use the red only to flag a key term or a chapter divider. Let the serif do the sentence, let the grotesque do the label.
